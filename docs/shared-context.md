## Authority

**`h5m-context` is authoritative for:**

- What High Five Moments is
- Initial audience, central problem, and core customer job
- Product proposition, positioning, and differentiation
- Cross-product principles and messaging guardrails
- Meaningful cross-project decisions

**This repository remains authoritative for:**

- Published website copy, metadata, and canonical URLs
- Page structure, conversion flows, and public-facing messaging as deployed
- Website implementation, analytics, consent, hosting, and deployment
- Website testing and release process

## Agent rules

1. Read shared product context before making claims about audience, positioning, or messaging.
2. Do not silently contradict `h5m-context`. Surface conflicts between published copy and shared context explicitly.
3. Do not copy the full product context into this repository.
4. If shared context is unavailable, state that canonical product truth cannot be inferred from published website copy alone.
